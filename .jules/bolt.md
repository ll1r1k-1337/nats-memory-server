## 2024-06-25 - Object Creation and Assignments in Builder Patterns
**Learning:** In performance-sensitive Builder patterns, using object spreading (`{ ...options, key: value }`) for every property update creates many intermediate objects that must be garbage collected and is significantly slower than direct assignment (`options.key = value`). In node, testing showed direct assignment to be ~50x faster.
**Action:** Use direct property assignment (`this.options.key = value`) in setter methods instead of object spreading (`this.options = { ...this.options, key: value }`) to avoid unnecessary object allocations. However, care must be taken to safely clone the state object during initialization (e.g., `this.options = { ...DEFAULT_OPTIONS }`) so that mutating `this.options` does not inadvertently mutate the shared default object.
