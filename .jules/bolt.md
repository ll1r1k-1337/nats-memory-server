## 2026-02-27 - Node.js Child Process Hangs with .unref()
**Learning:** Calling `.unref()` on a spawned child process (with `stdio: 'pipe'`) caused the parent process to hang indefinitely when `await`ing the `close` event, SPECIFICALLY when the child process's stderr stream was being consumed but not processed (verbose: false). This behavior was not observed when `verbose: true` (where data was logged to console). It appears that `unref()` interferes with the signal delivery or event loop processing required to detect the child process exit in this specific configuration.
**Action:** Avoid using `.unref()` on spawned server processes unless strictly necessary for "detach" behavior, and test thoroughly with both verbose and non-verbose modes if stream consumption logic differs.
