## 2024-05-24 - Zip-Slip / Path Traversal in File Downloads
**Vulnerability:** A path traversal vulnerability existed in `src/utils/download-file.ts` where the filename extracted from the `Content-Disposition` header was directly passed to `path.resolve(dir, fileName)` without sanitization. An attacker controlling the `Content-Disposition` header could use directory traversal sequences (e.g., `../../../etc/passwd`) to overwrite arbitrary files outside the intended download directory.
**Learning:** Even when reading from headers provided by HTTP clients/fetch, untrusted input must be sanitized. Standard string splitting (`.split('filename=')`) is insufficient and often leaves quotes in place.
**Prevention:** Always use `path.basename()` to strip off any directory components from file paths supplied by external sources before passing them to filesystem operations like `path.resolve()` or `fs.createWriteStream()`. Ensure quotes are properly removed via regex before calling `basename`.
